IDENTIFICATION DIVISION.
       PROGRAM-ID. FINANCIAL-CALCULATOR.
       AUTHOR. LLPT-NANO.

       DATA DIVISION.
       WORKING-STORAGE SECTION.
       01  WS-BALANCE        PIC 9(7)V99 VALUE 1000.00.
       01  WS-DEPOSIT        PIC 9(5)V99 VALUE 250.50.
       01  WS-NEW-BALANCE    PIC 9(7)V99.
       01  WS-INTEREST-RATE  PIC V99 VALUE .05.
       01  WS-INTEREST-GAINED PIC 9(5)V99.

       PROCEDURE DIVISION.
       MAIN-PROCEDURE.
           COMPUTE WS-NEW-BALANCE = WS-BALANCE + WS-DEPOSIT
           COMPUTE WS-INTEREST-GAINED = WS-NEW-BALANCE * WS-INTEREST-RATE
           ADD WS-INTEREST-GAINED TO WS-NEW-BALANCE

           DISPLAY "INITIAL BALANCE: " WS-BALANCE
           DISPLAY "NEW BALANCE AFTER DEPOSIT & INTEREST: " WS-NEW-BALANCE
           STOP RUN.
