# LLPT Code Nano

**LLPT Code Nano** é o modelo ultralight especializado em programação, dimensionado com **1 bilhão de parâmetros**. Desenvolvido especificamente para autocompletar código em tempo real e sugestões instantâneas em IDEs.

---

## 📊 Especificações Técnicas

- **Família:** LLPT Code (Programação)
- **Escala de Parâmetros:** 1B (1 Bilhão)
- **Janela de Contexto Planejada:** 8.192 tokens
- **Hardware Recomendado:** CPU moderna / GPU local (4GB VRAM)
- **Latência Alvo:** Sub-50ms para autocompletar inline

---

## 🎯 Casos de Uso Recomendados

- Autocompletar trechos de código (Inline Completion) em editores como VS Code e Neovim.
- Sugestão instantânea de nomes de variáveis, imports e assinaturas de funções.
- Docstrings rápidos e geração de comentários de código.

---

## 🛠️ Arquitetura e Estrutura

- **Tokenizer:** Tokenizer otimizado para sintaxe de linguagem de programação (Python, JavaScript/TypeScript, Go, Rust, C++, Java).
- **Otimizações:** Fill-In-the-Middle (FIM) nativo para preenchimento de código no meio de arquivos.
- **Status:** Em planejamento e estruturação inicial.
