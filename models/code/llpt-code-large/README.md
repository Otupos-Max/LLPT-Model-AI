# LLPT Code Large

**LLPT Code Large** é um modelo de alta capacidade com **70 bilhões de parâmetros**, desenvolvido para compreender repositórios inteiros, arquiteturas complexas de software e engenharia de sistemas.

---

## 📊 Especificações Técnicas

- **Família:** LLPT Code (Programação)
- **Escala de Parâmetros:** 70B (70 Bilhões)
- **Janela de Contexto Planejada:** 65.536 tokens
- **Hardware Recomendado:** Dual GPU ou Servidor (48GB - 80GB VRAM)
- **Formato Target:** Safetensors / vLLM / TensorRT-LLM

---

## 🎯 Casos de Uso Recomendados

- Análise e auditoria de segurança em código-fonte em grande escala.
- Design de arquitetura de software e planejamento de microsserviços.
- Migração de sistemas legados para tecnologias modernas.
- Diagnóstico avançado de concorrência, vazamento de memória e performance.

---

## 🛠️ Arquitetura e Estrutura

- **Capacidades:** Raciocínio profundo sobre dependências de código, AST (Abstract Syntax Trees) e grafos de execução.
- **Status:** Em planejamento e estruturação inicial.
