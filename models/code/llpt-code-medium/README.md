# LLPT Code Medium

**LLPT Code Medium** conta com **30 bilhões de parâmetros** e é o modelo ideal para agentes autônomos de engenharia de software e resolução de tarefas complexas em repositórios.

---

## 📊 Especificações Técnicas

- **Família:** LLPT Code (Programação)
- **Escala de Parâmetros:** 30B (30 Bilhões)
- **Janela de Contexto Planejada:** 32.768 tokens
- **Hardware Recomendado:** GPU Profissional (24GB VRAM - RTX 3090/4090 / A10)
- **Formato Target:** Safetensors / vLLM

---

## 🎯 Casos de Uso Recomendados

- Agentes de codificação autônomos (ex: correção de issues em repositórios).
- Análise de depuração (debugging) em nível de sistema.
- Refatoração arquitetural de múltiplos arquivos interligados.
- Geração e revisão de Pull Requests.

---

## 🛠️ Arquitetura e Estrutura

- **Suporte:** Suporte a contexto estendido para ler múltiplos arquivos de um projeto.
- **Atributos:** Treinamento especializado em algoritmos, estruturas de dados e raciocínio lógico.
- **Status:** Em planejamento e estruturação inicial.
