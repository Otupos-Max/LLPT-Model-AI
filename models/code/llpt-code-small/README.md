# LLPT Code Small

**LLPT Code Small** é um modelo especializado com **10 bilhões de parâmetros**, projetado para oferecer um excelente equilíbrio entre velocidade de geração e precisão em tarefas de desenvolvimento de software.

---

## 📊 Especificações Técnicas

- **Família:** LLPT Code (Programação)
- **Escala de Parâmetros:** 10B (10 Bilhões)
- **Janela de Contexto Planejada:** 16.384 tokens
- **Hardware Recomendado:** GPU Intermediária (12GB a 16GB VRAM)
- **Formato Target:** Safetensors / GGUF / Ollama integration

---

## 🎯 Casos de Uso Recomendados

- Geração de funções completas a partir de especificações.
- Refatoração rápida de código e correção de erros simples.
- Conversão de código entre diferentes linguagens de programação.
- Criação de testes unitários automatizados.

---

## 🛠️ Arquitetura e Estrutura

- **Recursos:** Suporte a Fill-In-the-Middle (FIM), compreensão de sintaxe de dezenas de linguagens.
- **Treinamento:** Treinado em corpus limpo de código open-source e dados sintéticos de alta qualidade.
- **Status:** Em planejamento e estruturação inicial.
