LLPT — Large Language para Trabalho

Uma família de modelos de inteligência artificial voltada para trabalho, desenvolvimento de software, raciocínio e tarefas gerais.

O LLPT é um projeto de IA que reúne duas famílias principais de modelos: LLPT, para uso geral, e LLPT Code, especializada em programação e engenharia de software.

O projeto possui diferentes escalas de modelos, desde versões menores até arquiteturas planejadas com trilhões de parâmetros.

Modelos destinados a tarefas gerais de linguagem, assistência, análise, raciocínio e produtividade.

Objetivos do projeto

- Desenvolver uma família própria de modelos de linguagem.
- Criar modelos em diferentes escalas de capacidade.
- Especializar modelos para programação e engenharia de software.
- Explorar raciocínio, compreensão de contexto e resolução de problemas.
- Estruturar uma base para futuras versões e melhorias.
- Integrar os modelos a ferramentas e plataformas de IA.

Arquitetura e desenvolvimento

Cada modelo poderá possuir sua própria configuração de arquitetura, conjunto de dados, tokenizer, estratégia de treinamento e método de inferência.

As decisões técnicas serão documentadas conforme o desenvolvimento de cada versão, incluindo:

- Arquitetura neural e quantidade de parâmetros.
- Dados e metodologia de treinamento.
- Uso de memória e requisitos de hardware.
- Contexto máximo e capacidades.
- Avaliações de qualidade e desempenho.
- Formatos de distribuição e inferência.

A quantidade de parâmetros, isoladamente, não determina a qualidade ou a velocidade de um modelo. Arquitetura, dados, treinamento e otimização também são fatores importantes.

Status

Status geral: em planejamento e desenvolvimento.

Os números apresentados representam as escalas planejadas para a família LLPT. A disponibilidade dos pesos, o estado do treinamento e os resultados de avaliação deverão ser documentados individualmente para cada modelo.
